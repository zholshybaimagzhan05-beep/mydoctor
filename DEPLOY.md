# mydoctor: бесплатный хостинг

Проект подготовлен для бесплатного деплоя на Render как Python Web Service.

## Что уже настроено

- `render.yaml` создает бесплатный web-сервис с именем `mydoctor`.
- `requirements.txt` использует `opencv-python-headless`, чтобы OpenCV корректно собирался на сервере без GUI.
- `Procfile` добавлен как запасной формат запуска для платформ, которые читают Procfile.
- `.gitignore` исключает локальную SQLite-базу, виртуальное окружение и временные файлы.

## Как опубликовать бесплатно

1. Создайте репозиторий на GitHub и загрузите туда эти файлы.
2. Откройте Render Dashboard.
3. Нажмите `New` -> `Blueprint`.
4. Подключите GitHub-репозиторий с проектом.
5. Render прочитает `render.yaml` и создаст сервис `mydoctor` на free-плане.
6. После первого деплоя приложение будет доступно по бесплатному поддомену вида:

```text
https://mydoctor.onrender.com
```

Если имя `mydoctor` уже занято в Render, измените поле `name` в `render.yaml`, например:

```yaml
name: mydoctor-kz
```

Тогда бесплатный адрес будет в формате `https://mydoctor-kz.onrender.com`.

## Важное ограничение бесплатного тарифа

На бесплатном Render локальные файлы временные. SQLite-база будет создаваться заново после рестарта или нового деплоя. Для демо-MVP это нормально, потому что приложение автоматически создает таблицы и демо-данные при запуске. Для реальной медицинской платформы нужно заменить SQLite на постоянную базу данных.

## Локальный запуск

```bash
uvicorn main:app --reload
```
